# ZeroFood API

**Global Solution 2026/2 - Domain Driven Design Using Java**

API RESTful para o marketplace B2B ZeroFood, desenvolvida com Spring Boot, JDBC puro e Oracle Database.

## Links
- **API no Render:** https://zerofood-zzer.onrender.com
- **Repositório GitHub:** https://github.com/di-zanon/ZeroFoodAPI
- **Front-end:** https://zerofod.vercel.app/
- **Vídeo de Apresentação:** https://www.youtube.com/watch?v=VCa_yUg_3cs

## Tecnologias
- Java 21
- Spring Boot 4.1.2
- JDBC (Oracle)
- Bean Validation
- Docker

## Como Rodar Localmente
1. Clone o repositório
2. Configure as variáveis de ambiente: `ORACLE_URL`, `ORACLE_USER`, `ORACLE_PASSWORD`
3. Execute `./mvnw spring-boot:run`
